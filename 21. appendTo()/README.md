我用**大白话 + 对比 + 例子**帮你彻底搞懂 `.appendTo()` 👇

---

# 一句话理解

👉 **`.appendTo()` 就是：把“前面的元素”插到“后面的目标里面（尾部）”**

```js
$(内容).appendTo(目标);
```

---

# 🔥 核心思路（最重要）

和 `.append()` 做个对比你就秒懂了：

| 方法          | 写法                     | 谁在前面 | 含义           |
| ------------- | ------------------------ | -------- | -------------- |
| `.append()`   | `$(目标).append(内容)`   | 目标     | 往目标里加内容 |
| `.appendTo()` | `$(内容).appendTo(目标)` | 内容     | 把内容丢进目标 |

👉 本质一样，只是**语法顺序反了** ([jQuery API][1])

---

# 🧠 通俗比喻

想象你往盒子里放东西：

- `.append()` 👉 **“把东西放进盒子”**
- `.appendTo()` 👉 **“把这个东西，放到那个盒子里”**

只是说话方式不同，本质一样。

---

# 📌 例子 1：创建元素并插入

```js
$("<p>Test</p>").appendTo(".inner");
```

👉 翻译成人话：

👉 “创建一个 `<p>`，然后把它放进 `.inner` 里面”

效果：

```html
<div class="inner">
  原内容
  <p>Test</p>
</div>
```

---

# 📌 例子 2：移动已有元素

```js
$("h2").appendTo(".container");
```

👉 意思：

👉 “把页面里的 h2 移动到 `.container` 里面”

⚠️ 注意：不是复制，是**移动！** ([jQuery API][1])

---

# 📌 多个目标的特殊规则（重点）

如果目标有多个：

```js
$("<p>Test</p>").appendTo(".inner");
```

假设 `.inner` 有 2 个：

👉 结果是：

- 第 1 个：插入 **克隆**
- 最后一个：插入 **原件**

✔ jQuery 会自动帮你复制 ([jQuery API][1])

---

# ⚠️ 常见坑（面试爱问）

## ❌ 错误写法

```js
$("hello").appendTo("p");
```

👉 这是找 `<hello>` 标签（不存在）

---

## ✅ 正确写法

```js
$("<span>hello</span>").appendTo("p");
```

👉 这样才是创建元素再插入

---

# ⚠️ 安全提醒（很重要）

```js
$("<div>" + 用户输入 + "</div>").appendTo("body");
```

👉 这样会有 **XSS风险（注入攻击）** ([jQuery API][1])

✔ 正确做法：过滤 / 转义用户输入

---

# 🧾 最后总结（记住这 3 点就够了）

1. `.appendTo()` = 把元素插到目标最后
2. 和 `.append()` 一样，只是**写法反过来**
3. 插入已有元素时是**移动，不是复制（除非多个目标）**
