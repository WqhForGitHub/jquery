这个选择器可以理解成一句很“人话”的规则：

👉 **找出某个属性的值 = 指定值，或者“以这个值开头 + 一个短横线(-)”的元素**

---

## 一句话理解

`[name|="value"]` 的意思是：

👉 **属性值要么刚好是 value，要么是 value-xxx 这种格式**

✔ 会匹配：

- value
- value-后缀

❌ 不会匹配：

- valuexxx（没有 `-`）
- xxxvalue

---

## 用你给的例子解释

```html
<a hreflang="en">✔</a>
<a hreflang="en-UK">✔</a>
<a hreflang="english">✘</a>
```

```js
$("a[hreflang|='en']");
```

### 结果：

- `en` ✅（完全相等）
- `en-UK` ✅（en + - + 后缀）
- `english` ❌（不是 `en-` 开头） ([jQuery API][1])

---

## 通俗类比（重点！）

把它当成“语言筛选器”就很好理解：

| 属性值  | 是否匹配 `[hreflang | ="en"]`        | 原因 |
| ------- | ------------------- | -------------- | ---- |
| en      | ✅                  | 完全等于       |
| en-US   | ✅                  | en + - + 后缀  |
| en-UK   | ✅                  | 同上           |
| english | ❌                  | 不是 en- 开头  |
| zh-en   | ❌                  | 不是以 en 开头 |

---

## 为什么会有这个选择器？

这个语法本来是给“语言代码”用的，比如：

- en（英文）
- en-US（美式英语）
- en-GB（英式英语）

所以它的规则就是：

👉 **匹配某个“语言前缀”**

---

## 和其他类似选择器对比（帮你彻底搞懂）

| 选择器         | 含义                     |                        |
| -------------- | ------------------------ | ---------------------- |
| `[attr="en"]`  | 完全等于                 |                        |
| `[attr^="en"]` | 只要以 en 开头（更宽松） |                        |
| `[attr         | ="en"]`                  | en 或 en-xxx（更严格） |
| `[attr*="en"]` | 只要包含 en              |                        |

👉 重点区别：

- `^=`：随便 en 开头都行
- `|=`：必须是 **en 或 en-xxx**

---

## 总结（记住这一句就够了）

👉 `[attr|="value"]` =
**“等于 value，或者 value-开头（带短横线）”**
