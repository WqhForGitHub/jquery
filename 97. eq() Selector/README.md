我用**大白话**给你讲清楚 `:eq()` 是干嘛的👇

---

## 一句话理解

👉 `:eq(n)` 就是：
**“从一堆元素里，选第 n 个（从 0 开始数）”** ([jQuery API 文档][1])

---

## 举个最简单的例子

```js
$("li:eq(1)");
```

意思是：

- 先选中所有 `li`
- 然后拿 **第 1 个**
- ⚠️ 注意：从 0 开始数

所以：

| 写法    | 实际选中 |
| ------- | -------- |
| `eq(0)` | 第1个    |
| `eq(1)` | 第2个    |
| `eq(2)` | 第3个    |

👉 因为 JS 是从 0 开始的 ([jQuery API 文档][1])

---

## 再举个更直观的例子

HTML：

```html
<ul>
  <li>苹果</li>
  <li>香蕉</li>
  <li>橘子</li>
</ul>
```

代码：

```js
$("li:eq(1)").css("color", "red");
```

效果：

👉 “香蕉” 变红
（因为它是第 2 个）

---

## 还能倒着选（负数）

```js
$("li:eq(-1)");
```

👉 选 **最后一个**

```js
$("li:eq(-2)");
```

👉 倒数第二个 ([jQuery API 文档][1])

---

## 核心特点（很重要）

### 1️⃣ 它是“筛选”

不是重新找元素，而是：

👉 **在已经选中的元素里挑一个**

比如：

```js
$(".box:eq(2)");
```

流程是：

1. 先找到 `.box` 的所有元素
2. 再取第 2 个

---

### 2️⃣ 只选一个元素

👉 `:eq()` 永远只会选 **一个**

不像：

```js
:nth-child(2)
```

可以选多个

---

### 3️⃣ 已被淘汰（重点⚠️）

👉 从 jQuery 3.4 开始：

❌ `:eq()` 不推荐用了
✅ 推荐改成 `.eq()`

```js
// ❌ 旧写法
$("li:eq(1)");

// ✅ 新写法（推荐）
$("li").eq(1);
```

原因：

👉 `:eq()` 不是标准 CSS
👉 性能比 `.eq()` 差 ([jQuery API 文档][1])

---

## 和 `.eq()` 的区别（顺带帮你理解）

| 写法    | 类型   | 推荐      |
| ------- | ------ | --------- |
| `:eq()` | 选择器 | ❌ 已废弃 |
| `.eq()` | 方法   | ✅ 推荐   |

---

## 总结（记住这4点就够了）

👉 `:eq(n)` 本质就是：

1. 从一组元素里 **按位置选一个**
2. **从 0 开始**
3. 支持负数（倒着数）
4. ⚠️ **现在不推荐用，用 `.eq()` 代替**
