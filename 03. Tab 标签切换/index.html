jQuery 是一个快速、小型且功能丰富的 JavaScript 库。它使 HTML 文档遍历和操作、事件处理、动画和 Ajax 等事情变得更加简单，具有易于使用的 API，可在多种浏览器中工作。
jQuery 选择器基于 CSS 选择器，允许你通过元素名、属性、类名等方式选取 HTML 元素。基本语法为 $(selector).action()，支持 ID、类、元素、属性等丰富选择方式。
jQuery 事件处理简化了 JavaScript 的事件绑定。常用方法包括 click()、hover()、on() 等，支持事件委托，可以高效处理动态元素的事件绑定。

HTML（超文本标记语言）是构建网页内容的标准标记语言。它定义了网页的结构和语义，通过标签来组织文本、图片、链接等内容。HTML5 引入了更多语义化标签和 API。
CSS（层叠样式表）用于描述 HTML 文档的呈现方式。它控制布局、颜色、字体、间距等视觉效果，使网页更具吸引力和可用性。Flexbox 和 Grid 是现代布局的核心技术。
JavaScript 是一种动态编程语言，可为网页添加交互功能。它可以操作 DOM、处理事件、发送网络请求，是实现动态网页效果的核心技术。ES6+ 带来了箭头函数、Promise、模块化等现代特性。

设计原则
色彩理论
响应式设计
好的设计应该遵循一致性、可用性和可访问性原则。界面元素应保持统一的视觉风格，操作流程应符合用户直觉，同时要兼顾不同能力用户的使用需求。
色彩搭配需要考虑色相、饱和度和明度三个维度。互补色创造对比，类似色营造和谐。在 UI 设计中，常用 60-30-10 法则分配主色、辅色和强调色的比例。
响应式设计使网页能够自适应不同屏幕尺寸。通过媒体查询、弹性布局和相对单位，确保内容在手机、平板和桌面设备上都能良好展示。

React 由 Meta 开源，使用虚拟 DOM 实现高效渲染。它采用声明式编程范式，通过 JSX 描述 UI 结构，配合 Hooks API 管理状态和副作用。
Vue 由尤雨溪创建，以渐进式架构著称。它结合了 React 和 Angular 的优点，提供了响应式数据绑定、组件化开发等特性，学习曲线平缓。
Angular 由 Google 维护，是一个完整的前端开发框架。它使用 TypeScript 开发，内置依赖注入、路由、表单处理等模块，适合大型企业级应用。
