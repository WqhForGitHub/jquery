用一句最简单的话来说：

👉 **`.empty()` 就是把一个元素“掏空”，但不把这个元素本身删掉。**

---

## 🔍 通俗理解

你可以把 HTML 元素想成一个盒子：

```html
<div class="hello">
  Hello
  <span>World</span>
</div>
```

这个 `<div>` 就像一个盒子，里面有：

- 文本：Hello
- 子标签：`<span>World</span>`

---

### 🧹 执行 `.empty()` 之后

```js
$(".hello").empty();
```

结果变成：

```html
<div class="hello"></div>
```

✔ 盒子还在
❌ 里面的东西（文字 + 子元素）全部清空了

👉 相当于：**把内容全部删除，但保留外壳**

---

## 📌 关键点总结

- 删除内容：✔
  - 子元素（标签）
  - 文本（文字）

- 保留元素本身：✔
- 不需要参数：✔
- 会顺带清除事件和数据（避免内存问题） ([jQuery API][1])

---

## 💡 和类似方法对比（很重要）

| 方法        | 做什么                               |
| ----------- | ------------------------------------ |
| `.empty()`  | 清空内容（保留元素）                 |
| `.remove()` | 连元素一起删掉                       |
| `.detach()` | 删除元素但保留数据（以后还能加回来） |

---

## 🧠 一句话记忆

👉 **empty = 清空里面，不动外壳**
