什么是 jQuery？
▶
jQuery 是一个快速、小型且功能丰富的 JavaScript 库。它使 HTML 文档遍历和操作、事件处理、动画和 Ajax 等事情变得更加简单，具有易于使用的 API，可在多种浏览器中工作。
jQuery 的优势是什么？
▶
jQuery 的主要优势包括：简洁的语法、出色的跨浏览器兼容性、丰富的插件生态、强大的选择器引擎、以及内置的动画效果支持。它极大地简化了 DOM 操作和事件处理。
如何引入 jQuery？
▶
可以通过 CDN 引入 jQuery，例如使用 jsDelivr 或 cdnjs 等公共 CDN。也可以下载 jQuery 文件到本地，然后通过 <script> 标签引入。推荐使用 CDN 方式以获得更快的加载速度。

HTML 基础
▶
HTML（超文本标记语言）是构建网页内容的标准标记语言。它定义了网页的结构和语义，通过标签来组织文本、图片、链接等内容。
CSS 基础
▶
CSS（层叠样式表）用于描述 HTML 文档的呈现方式。它控制布局、颜色、字体、间距等视觉效果，使网页更具吸引力和可用性。
JavaScript 基础
▶
JavaScript 是一种动态编程语言，可为网页添加交互功能。它可以操作 DOM、处理事件、发送网络请求，是实现动态网页效果的核心技术。

前端框架对比
▶
React 由 Meta 开发，采用虚拟 DOM 和 JSX 语法；Vue 由尤雨溪创建，以渐进式架构著称；Angular 由 Google 维护，提供完整的开发框架。三者各有优势，选择取决于项目需求。
构建工具演进
▶
从 Grunt 到 Gulp，再到 Webpack、Rollup、Vite 和 esbuild，前端构建工具不断演进。Vite 利用原生 ES Module 实现了极速开发体验，成为当前最流行的选择之一。
TypeScript 的崛起
▶
TypeScript 为 JavaScript 添加了静态类型检查，显著提升了代码可维护性和开发体验。它已成为大型前端项目的标配，Angular、Vue 3 和 Deno 等都原生支持 TypeScript。

设计原则
▶
好的设计应该遵循一致性、可用性和可访问性原则。界面元素应保持统一的视觉风格，操作流程应符合用户直觉，同时要兼顾不同能力用户的使用需求。
色彩理论
▶
色彩搭配需要考虑色相、饱和度和明度三个维度。互补色创造对比，类似色营造和谐。在 UI 设计中，常用 60-30-10 法则分配主色、辅色和强调色的比例。
响应式设计
▶
响应式设计使网页能够自适应不同屏幕尺寸。通过媒体查询、弹性布局和相对单位，确保内容在手机、平板和桌面设备上都能良好展示。
