## 一、blur 事件到底是干嘛的？

👉 一句话：

> **blur = 元素“失去焦点”的时候触发的事件** ([jQuery API Documentation][1])

---

### 什么叫“失去焦点”？

你可以把“焦点”理解为：
👉 当前正在操作的那个输入框

比如：

- 你正在输入 `<input>`
- 这个输入框就是“有焦点”
- 当你：
  - 点到别的地方
  - 或按 Tab 切走
    👉 它就“失去焦点” → 触发 blur

---

## 二、举个最简单例子

```html
<input id="name" type="text" />
```

```js
$("#name").on("blur", function () {
  alert("你离开输入框了！");
});
```

👉 效果：

1. 点进输入框（开始输入）
2. 再点页面其他地方
   👉 就会弹出提示

---

## 三、用人话理解

你可以这样记：

| 事件  | 含义       |
| ----- | ---------- |
| focus | 你“点进来” |
| blur  | 你“离开了” |

👉 就像：

- focus：进房间
- blur：出房间

---

## 四、什么时候会触发？

以下情况都会触发 blur：

- 点击页面其他地方
- 按 Tab 切换输入框
- JS 主动让它失去焦点
  👉 本质：**焦点转移了** ([MDN Web Docs][2])

---

## 五、手动触发 blur（重点）

```js
$("#name").trigger("blur");
```

👉 作用：

> 不用用户操作，代码直接“模拟离开输入框”

---

## 六、常见用途（很重要）

### 1️⃣ 表单校验（最常见）

```js
$("#email").on("blur", function () {
  if ($(this).val() === "") {
    alert("不能为空！");
  }
});
```

👉 用户一离开输入框，就检查

---

### 2️⃣ 自动保存 / 提交

```js
$("#title").on("blur", function () {
  saveData();
});
```

---

### 3️⃣ UI 控制

- 隐藏提示框
- 收起下拉菜单
- 关闭搜索建议

---

## 七、一个容易踩坑的点 ⚠️

👉 blur **不会冒泡**

意思是：

```js
$("#parent").on("blur", function () {});
```

👉 可能监听不到子元素的 blur

所以 jQuery 内部用的是：

👉 `focusout` 来解决这个问题 ([jQuery API Documentation][1])

---

## 八、总结（面试版）

👉 一句话总结：

> **blur 是当元素失去焦点时触发的事件，常用于表单校验和用户输入结束的处理**
