## 一句话理解 `.add()`

👉 **`.add()` 就是：把“更多元素”加进来，一起操作**

就像你本来选中了 A，现在再把 B 加进来 → 一起处理。

---

## 1️⃣ 它到底在干嘛？

```js
$("p").add("div");
```

👉 实际效果：

> 原本选中所有 `<p>`
> 再把 `<div>` 也加进来
> 👉 最终变成：`p + div`

然后你可以：

```js
$("p").add("div").css("color", "red");
```

👉 p 和 div 一起变红

---

## 2️⃣ 为什么说“返回新集合”？（重点）

很多人这里会翻车 👇

```js
var pdiv = $("p");
pdiv.add("div"); // ❌ 没效果
```

👉 原因：

`.add()` **不会改原来的变量！**

它是：

> ✔ 生成一个“新的组合结果”
> ❌ 不会修改原来的 `pdiv`

---

✅ 正确写法：

```js
var pdiv = $("p");
pdiv = pdiv.add("div"); // ✔
```

或者链式：

```js
$("p").add("div").addClass("widget");
```

---

## 3️⃣ 一个非常形象的比喻

你可以把 `.add()` 想成：

> 🧺 “往篮子里再放东西，但会给你一个新篮子”

- 原篮子：`$("p")`
- 新篮子：`$("p").add("div")`

---

## 4️⃣ 参数可以是什么？

几乎啥都能加 👇

### ✔ 选择器

```js
$("li").add("p");
```

---

### ✔ DOM 元素

```js
$("li").add(document.getElementsByTagName("p")[0]);
```

---

### ✔ HTML（创建新元素）

```js
$("li").add("<p>new</p>");
```

⚠️ 注意：

👉 只是“创建并加入集合”，**不会自动显示在页面**

要显示必须：

```js
.appendTo("body")
```

---

## 5️⃣ 排序规则（很多人忽略）

你可能以为：

```js
$("p").add("div");
```

👉 顺序是：p → div ❌

其实：

👉 **会按 DOM 结构顺序重新排序**

比如 HTML：

```html
<div></div>
<p></p>
```

👉 最终顺序是：

```
div → p
```

不是你写的顺序！

---

## 6️⃣ 实际例子（你给的那个）

HTML：

```html
<ul>
  <li>1</li>
  <li>2</li>
</ul>
<p>a paragraph</p>
```

JS：

```js
$("li").add("p").css("background", "red");
```

👉 结果：

- 所有 `li`
- 加上 `p`
- 👉 一起变红

---

## 7️⃣ 动态创建但没显示（经典坑）

```js
$("li").add("<p id='new'>new</p>").css("background", "red");
```

👉 会发生：

- 新 p 被创建 ✔
- 背景变红 ✔
- **但页面看不到 ❌**

👉 因为没插入 DOM！

---

✅ 正确：

```js
$("li").add("<p id='new'>new</p>").css("background", "red").appendTo("body");
```

---

## 8️⃣ 怎么“撤销 add”？（进阶）

```js
$("p").add("div").end();
```

👉 `.end()`：回到 add 之前（只剩 p）

或者：

```js
.not("div")
```

👉 删除 div

---

## 9️⃣ 最终总结（重点记这个）

👉 `.add()` =

> ✔ 扩展选择范围
> ✔ 返回新集合
> ❌ 不改变原对象
> ❌ 不会插入 DOM

---

## 🔥 用一句最通俗的话

👉 `.add()` 就是：

> **“多选几个元素，一起操作，但不会帮你改页面结构”**
