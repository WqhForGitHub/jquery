我用**大白话 + 一步一步**给你讲清楚 `.addBack()` 👇

---

## 一句话理解

👉 **`.addBack()` = 把“上一步选中的元素”也加回来**

---

## 核心原理（很关键）

jQuery 在链式调用时，有一个“**历史记录栈（stack）**”：

- 每执行一步（比如 `.find()`、`.nextAll()`）
- 就会产生一个新的元素集合
- 同时把“上一步的结果”保存起来 ([jQuery API][1])

👉 `.addBack()` 的作用就是：
**把“上一步的结果” + “当前结果” 合并在一起**

---

## 用你给的例子讲（最清楚）

HTML：

```html
<ul>
  <li>1</li>
  <li>2</li>
  <li class="third-item">3</li>
  <li>4</li>
  <li>5</li>
</ul>
```

代码：

```js
$("li.third-item") // 第一步：选中 3
  .nextAll() // 第二步：选中 4, 5
  .addBack() // 第三步：把 3 加回来
  .css("background", "red");
```

---

## 执行过程拆解

### ① 第一步

```js
$("li.third-item");
```

👉 当前选中：

```
[3]
```

---

### ② 第二步

```js
.nextAll()
```

👉 变成：

```
[4, 5]
```

👉 注意：此时 **3 被“挤掉”了，但还在栈里**

---

### ③ 第三步（关键）

```js
.addBack()
```

👉 把上一步（3）加回来：

```
[3, 4, 5]
```

✔ 最终结果就是这三个元素一起操作 ([jQuery API][1])

---

## 再用一个更直觉的类比

你可以把它理解成：

```
步骤1：你选了A
步骤2：你选了B（A暂时放旁边）
步骤3：addBack → 把A拿回来
```

👉 最终 = A + B

---

## selector 参数是干嘛的？

```js
.addBack(".xxx")
```

👉 表示：

只把“上一步中符合 .xxx 的元素”加回来

---

## 常见使用场景

### 1️⃣ 找子元素 + 再包含父元素

```js
$("div").find("p").addBack();
```

👉 结果：

```
div + p 都选中
```

👉 如果没有 `.addBack()`：

```
只会选中 p
```

---

## 总结（记住这3点就够了）

1. `.addBack()` = 把“上一步选中的元素”加回来
2. 常用于链式操作中“补回原来的元素”
3. 本质是：**合并两个选择结果（当前 + 上一个）**
