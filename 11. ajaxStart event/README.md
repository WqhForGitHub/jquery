## 一句话理解 ajaxStart

👉 **ajaxStart 就是：当“第一个 Ajax 请求开始时”触发的事件**

---

## 通俗场景举例

你可以把 Ajax 请求想象成“后台任务”：

- 用户点按钮 → 开始请求数据
- 页面在加载 → 还没返回结果
- 加载完成 → 显示结果

那么：

👉 **ajaxStart = “刚开始加载的那一刻”**

---

## 更直白一点

假设你页面里有很多 Ajax 请求：

- 第1个请求开始 → ✅ 触发 ajaxStart
- 第2个请求开始（第1个还没结束） → ❌ 不触发
- 第3个请求开始 → ❌ 也不触发

👉 只有“从 0 个请求 → 变成 1 个请求”时才触发
（也就是“第一个开始”） ([documentation.help][1])

---

## 和 ajaxSend 的区别（顺便帮你理解）

| 事件      | 什么时候触发                             |
| --------- | ---------------------------------------- |
| ajaxStart | **第一个 Ajax 请求开始时（只触发一次）** |
| ajaxSend  | 每一个 Ajax 请求发送前都会触发           |

👉 重点区别：

- ajaxStart：全局“开关”
- ajaxSend：每次请求都会执行

---

## 常见用途（重点）

最典型就是👇

👉 **显示加载动画（loading）**

```js
$(document).on("ajaxStart", function () {
  $("#loading").show();
});
```

意思就是：

👉 只要开始请求数据（而且当前没有其他请求），就显示 loading

---

## 为什么要这样设计？

因为：

👉 页面可能会有多个 Ajax 请求

如果每个都显示 loading：

- 会闪来闪去 ❌
- 用户体验很差 ❌

所以 jQuery 设计成：

👉 **只在“开始有请求时”触发一次** ([jQuery 学习中心][2])

---

## 再总结一遍（记住这3点就够了）

👉 ajaxStart = 第一个 Ajax 请求开始时触发

👉 只触发一次（不是每个请求）

👉 常用于：显示 loading / 禁用按钮
