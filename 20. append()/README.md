# 一、`.append()` 是什么？（一句话）

👉 `.append()` 就是：

> **把内容加到某个元素“里面的最后面”**

---

# 二、生活类比（最重要）

想象你有一个盒子：

```html
<div class="box">苹果</div>
```

你执行：

```js
$(".box").append("香蕉");
```

结果变成：

```html
<div class="box">苹果 香蕉</div>
```

👉 重点：

✔ 加在里面
✔ 加在最后
❌ 不会覆盖原来的内容
❌ 不会替换

---

# 三、官方这句话的白话翻译

原文：

> Insert content to the end of each element

翻译成大白话：

> 把内容塞到每个选中的元素里面的“最后一格”

---

# 四、核心规则（非常重要）

## 1️⃣ 插入位置

```
父元素
 ├── 原内容
 └── append 的内容（追加到最后）
```

---

## 2️⃣ 不会替换

```js
$("p").append("Hello");
```

不会变成：

❌ 原内容消失

而是：

✔ 原内容 + Hello

---

## 3️⃣ 可以同时加很多个元素

```js
$("body").append("<div>1</div>", "<div>2</div>");
```

👉 一次加多个

---

# 五、3种常见用法（你文档里的重点）

---

## ① 加 HTML 字符串

```js
$("p").append("<b>Hello</b>");
```

👉 在 p 标签里面加粗字

---

## ② 加 DOM 元素

```js
$("p").append(document.createTextNode("Hello"));
```

👉 加纯文本节点

---

## ③ 加 jQuery 对象（重点）

```js
$("p").append($("strong"));
```

👉 把页面上的 `<strong>` 移进去

⚠️ 注意：

- 不是复制
- 是“搬家”（原来的位置会消失）

---

# 六、append vs appendTo（考试常考）

## append

```js
$("A").append("B");
```

👉 B 加到 A 里面

---

## appendTo

```js
$("B").appendTo("A");
```

👉 写法反过来，但效果一样

---

# 七、最容易踩坑的点（重点）

## ❗ 1. append 是“移动”不是复制

```js
$("h2").appendTo(".container");
```

👉 h2 会被搬走，不会留在原地

---

## ❗ 2. 多个目标会“克隆”

```js
$(".box").append($("h2"));
```

如果 `.box` 有多个：

👉 最后一个是原元素
👉 其他是 clone（复制品）

---

## ❗ 3. 安全问题（XSS）

如果你写：

```js
$("div").append(userInput);
```

👉 用户输入可能插入恶意代码

⚠️ 所以必须过滤输入

---

# 八、总结（最简单版本）

👉 `.append()` =

> 往选中的元素里面，**最后面塞东西**

---

# 九、给你一句“记忆口诀”

🧠

> append = 往里面加 + 加在最后 + 不替换
