我用**大白话**帮你把 `.each()` 讲清楚👇

---

## 一、它是干嘛的？

👉 一句话：

**`.each()` 就是用来“挨个处理一堆元素”的工具。**

比如你选中了很多 `<li>`，它可以帮你一个一个去操作它们。 ([api.jquery.com][1])

---

## 二、用生活例子理解 🌰

假设你有一排人（DOM元素）：

```
<li>张三</li>
<li>李四</li>
<li>王五</li>
```

你想让每个人都说一句话。

👉 `.each()` 就像：

> “排队，一个一个来！”

---

## 三、基本写法

```js
$("li").each(function (index, element) {
  // 对每一个 li 做点事情
});
```

👉 里面这个函数会执行很多次（每个元素一次）

---

## 四、两个重要参数

### 1️⃣ index（索引）

- 当前是第几个（从 0 开始）
- 类似：第0个、第1个、第2个

### 2️⃣ element（元素）

- 当前这个DOM元素

---

## 五、最关键：this 是谁？

👉 在 `.each()` 里面：

```
this === 当前正在处理的那个元素
```

比如：

```js
$("li").each(function () {
  console.log($(this).text());
});
```

👉 输出：

```
张三
李四
王五
```

📌 因为 `this` 每次都指向不同的 `<li>` ([jquery123.com][2])

---

## 六、最简单理解方式（核心）

你可以把 `.each()` 当成：

```js
for (每一个元素) {
    执行函数
}
```

👉 只是 jQuery 帮你写好了循环，不用自己写 `for`

---

## 七、怎么停止循环？

```js
return false;
```

👉 相当于：

```
break;
```

---

## 八、常见误区（很重要⚠️）

### ❌ 不用 each 的情况

```js
$("li").each(function () {
  $(this).addClass("red");
});
```

👉 其实可以直接写：

```js
$("li").addClass("red");
```

📌 因为 jQuery 自己就会帮你循环（叫“隐式迭代”） ([api.jquery.com][1])

---

## 九、一句话总结

👉 `.each()` =
**“对选中的一堆元素，一个一个执行函数”**
